# MindShield

A firewall for your attention. A study-focus website for exam season, built for the Mastery of Mind (MAOM) course, Cybersecurity branch.

**Team:** Visva Thomas Cristober, Sanjay Kaarthikeyan Bharath Kumar, Shreehari Manoj Kumar

## What it does
- Focus timer (1, 25, 45, 60 minutes) with a tree that grows while you study
- Pause screen with a breathing countdown when you leave the tab during a session
- Study Garden with streaks, levels (Seed, Sprout, Tree, Forest Guardian) and a weekly chart
- Night Mode rest screen and a PIN against tampering
- Privacy first: all data stays in your browser (localStorage). No server, no account, no analytics.

## Run it
Open `index.html` in any browser. No build step.
